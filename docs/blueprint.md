# **App Name**: SanctuaryLink

## Core Features:

- Role-Based Authentication: Enable secure sign-up and login with Firebase Authentication, providing distinct access levels for Admin, Treasurer, and Member roles to ensure data integrity and privacy, with role data managed in Firestore.
- Comprehensive Member Management: Admin users can add, edit, search, filter, and delete member profiles, storing essential information like contact details, ministry groups, and membership status in Firestore.
- Donation & Income Tracking: Record and categorize various income types (Tithe, Offering, GoFund), with options for payment methods and notes. Display key income metrics and generate basic monthly/yearly reports from Firestore data.
- Expense Management & Categorization: Track and categorize church expenses (e.g., Utility, Rent, Salary), including amount, date, approval, and description, with data securely stored in Firestore.
- Core Financial Reporting Dashboard: Display essential financial summaries like total income/expenses this month, balance calculation, and a comparison chart, pulling real-time data from Firestore for transparency.
- AI Financial Anomaly Tool: An AI tool that proactively alerts Admin users to significant income decreases compared to previous periods, drawing insights from historical donation data stored in Firestore.
- Community Announcements & Events: Admin users can post new announcements and upcoming events with descriptions. Members can view these updates and RSVP.

## Style Guidelines:

- Primary color: Deep, authoritative blue (#2D4EB2), representing trust, professionalism, and spiritual depth.
- Background color: A very light, subtle blue-grey (#ECEFF2), providing a clean and calm canvas that enhances readability.
- Accent color: A warm, sophisticated gold (#EBB41D), used for highlighting key information, interactive elements, and providing an elegant contrast.
- Font: 'Inter' (sans-serif) for all text elements. This modern, neutral, and highly readable typeface is suitable for displaying diverse information, from financial reports to member details, maintaining a professional aesthetic.
- Use clear, modern icons for navigation and data visualization, incorporating subtle church-themed elements where appropriate for visual harmony, rather than literal religious symbols.
- A responsive design featuring a persistent left-hand sidebar for main navigation and a dynamic content area that adapts seamlessly to various screen sizes.
- Subtle transitions for dashboard state changes, form submissions, and data updates to enhance user experience without causing distraction or hindering efficiency.
